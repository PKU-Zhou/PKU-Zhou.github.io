**如何将.lib转化为.db ？**
```bash
# 启动library compiler shell
lc_shell 

# 转换
read_lib xxx.lib 
write_lib xxx0 -format db -output xxx.db
# 注意此处的xxx0是原先lib文件中lib名（并非文件名，虽然一般lib名和文件名一样）

```
